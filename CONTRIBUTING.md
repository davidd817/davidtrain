# Contribuir

1. Lee `AGENTS.md` y revisa `git status` antes de empezar.
2. Mantén el alcance en el módulo de entrenamiento y evita cambios destructivos en Supabase.
3. Usa imports con alias `@/` y componentes reutilizables cuando ya exista un patrón.
4. Ejecuta `npm run lint`, `npm run typecheck`, `npm test` y `npm run build`.
5. Explica en la revisión cualquier cambio de datos, Auth, RLS o migraciones.

Los cambios de UI deben incluir una captura en el Pull Request cuando sea útil. No incluyas secretos, `.env.local`, dumps de base de datos ni datos reales de usuarios.
