# Seguridad

No reportes vulnerabilidades públicamente con credenciales, tokens o datos de usuarios. Si GitHub Private Vulnerability Reporting está habilitado, utiliza la opción “Report a vulnerability”. En caso contrario, contacta directamente con el propietario del repositorio sin publicar secretos.

Al informar, incluye una descripción reproducible sin secretos, impacto, alcance y una propuesta de mitigación. No ejecutes cambios remotos, migraciones ni pruebas destructivas como parte del informe.
